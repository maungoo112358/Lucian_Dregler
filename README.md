# Lucian Dregler - Hand-Tracked Rubik's Cube

A Three.js Rubik's cube you can control with the mouse, and (eventually) with your hands through the webcam.

## Getting started

```bash
npm install
npm run dev
```

Open the printed local URL. You should see a spinning cube (a smoke test for now).

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Dev server with hot reload |
| `npm run typecheck` | TypeScript check |
| `npm run build` | Typecheck + production build |
